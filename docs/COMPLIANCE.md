# 合规与内容治理基线

## 1. 适用范围与声明

平台只发布部署者有权或有明确再分发依据的资料元数据和链接。本文是工程基线，不是法律意见。中国大陆部署/运营前，必须由具备资质的专业人士按实际商业模式复核版权、个人信息、网络数据、广告/推广、算法、ICP 备案/许可、公安联网备案及网盘平台协议；相关结论按实施时最新官方规则更新。

## 2. 内容准入

允许：`owned`、`authorized`、`open_licensed`、`public_domain`，且有来源、有未过期依据、通过审核、链接可用、无投诉隐藏。

禁止：未授权影视/音乐/图书/漫画/课程/题库/付费社群；破解软件/密钥/盗版插件/绕过授权工具；数据库/个人信息/账号密码/Cookie/Token/商业机密；恶意软件/钓鱼/诈骗/规避平台安全机制工具；法律法规禁止传播的内容。免责声明、“仅供学习”或分类名不能替代权利证明。

## 3. 授权证据

记录来源 URL、来源名称/类型/录入方式、权利状态、许可名称/版本/原文 URL、授权方/范围/地区/商业推广许可、起止时间、说明、证据引用和哈希、审核人/时间/备注。证据文件进入私有对象存储或受控文件系统，数据库只存引用、哈希和必要元数据；联系方式和身份证明与公开资源字段隔离。

授权过期、撤回、证据不足或禁止内容立即阻断公开查询/跳转，并触发索引移除和管理员提醒。公开页面只显示必要的许可说明，不显示私人证据。

## 4. 投诉、侵权通知与恢复

公开页面提供无需登录的侵权通知、一般举报和状态查询。侵权通知至少包含通知人身份/联系方式、被投诉资源 URL、权利作品或原始来源、具体请求、初步证明和真实性声明；工单票据使用随机不可枚举 token。

收到材料完整且可信的通知后，事务内将资源置为 `temporarily_hidden` 并从公开 API/索引/推荐位/跳转阻断；记录时间、处理人、证据与状态变化，必要时在法律允许范围通知提交方。支持不侵权说明/恢复申请。最终可永久下架、维持隐藏、恢复发布或补充材料；恢复必须重新满足发布门槛。重复侵权来源/提交者/域名可进入黑名单。

投诉材料仅向获权 reviewer/admin 开放，按 `docs/DATA_RETENTION.md` 保存并删除；公众不能看到投诉人的证件、联系方式或证据。

## 5. 网盘与推广边界

MVP 只管理夸克、百度公开分享链接和允许域名的通用外链。适配器只能使用公开页面或正式开放接口；无法可靠判断时返回 `unknown`/`risk_controlled`，不绕过登录、验证码、签名、风控或 robots/服务条款。

保存 URL 前执行 HTTPS、域名允许列表、禁止用户信息段/非标准端口/IP/私网/保留地址/危险协议、规范化和带密钥去重哈希。跳转目标只能来自已审核数据库记录和后台启用渠道；渠道模板占位符白名单，不能透传任意查询参数。

推广按钮附近披露可能存在渠道/推广关系。只有签名、重放保护有效的官方回调或管理员导入的官方报表才能形成 `conversion_events`；点击不等于转化，不得推算/伪造拉新、转存、付费。

## 6. 页面公开告知

部署者必须公开服务条款、隐私政策、内容收录规则、版权/侵权通知规则、推广链接披露、联系方式和必要备案信息。隐私政策应说明本地搜索历史、搜索/点击事件、保存期限、访问范围、删除机制、必要的分析拒绝机制和不建立跨站画像。

## 7. 合规检查清单

- [ ] 内容来源/授权依据和有效期可审计。
- [ ] 未审核/撤回/过期/投诉/删除资源不可搜索、详情、跳转、sitemap、推荐。
- [ ] 证据与联系信息为私有数据，权限最小化，访问有审计。
- [ ] 网盘适配器与推广机制经平台最新官方文档/协议复核。
- [ ] 中国大陆上线前完成专业法律/备案评估并记录结论。
- [ ] 公开法律文本、联系方式、推广披露和备案信息已配置。
- [ ] 数据保留、删除、备份和恢复演练结果真实可复现。
