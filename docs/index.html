WHY THIS PROJECT

搜索体验可以简洁，内容边界必须清楚。

01

授权后收录

仅接收自有、明确授权、开放许可或公有领域资料，并保留可审计依据。

02

公开源优先

不抓取搜索引擎、私人群组、登录后内容，也不绕过验证码和网盘风控。

03

链接先确认

跳转前展示目标站点和推广关系；链接失效、撤权或被投诉后立即停止展示。
