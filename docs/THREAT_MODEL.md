# 威胁模型

## 1. 资产与安全目标

| 资产                       | 目标                                               |
| -------------------------- | -------------------------------------------------- |
| 公开资源与链接             | 只公开满足权利和审核门槛的内容；跳转目标不可被篡改 |
| 授权证据/联系方式/投诉材料 | 机密、最小权限、可审计、按期限删除                 |
| 管理员账号/会话/权限       | 身份真实性、不可越权、可撤销                       |
| PostgreSQL/审计/outbox     | 完整性、可恢复、变更可追溯                         |
| Meilisearch                | 可重建、不可绕过数据库公开状态                     |
| 点击/转化数据              | 指标真实性、隐私最小化、不可由点击伪造转化         |
| 备份/密钥                  | 机密、轮换、可恢复                                 |

## 2. 信任边界与攻击者

边界为公网浏览器->反向代理->web；web/worker->数据库/Redis/搜索/私有存储；worker/web->外部网盘；后台账号->高权限操作。攻击者包括匿名恶意访客、恶意提交者、低权限 editor、被盗管理员会话、恶意外链/网盘响应、供应链攻击者和误配置运维者。

## 3. STRIDE 风险登记

| ID   | 类别                   | 风险                            | 概率  | 影响  | 负责人              | 缓解                                                 | 剩余风险                     |
| ---- | ---------------------- | ------------------------------- | ----- | ----- | ------------------- | ---------------------------------------------------- | ---------------------------- |
| T-01 | Spoofing               | 管理员凭证/会话被盗             | 中    | 高    | web/security        | Argon2id、MFA 预留、HttpOnly、轮换、撤销、限流       | 终端被控仍需响应             |
| T-02 | Tampering              | editor 越权审核或篡改已发布权利 | 中    | 高    | core/db             | RBAC、所有权隔离、状态机、乐观锁、审计               | 配置错误需复核               |
| T-03 | Tampering              | outbox/索引不同步导致下架残留   | 中    | 高    | worker/search       | 事务 outbox、高优先级删除、DB 复核、告警、重建       | 短暂索引陈旧                 |
| T-04 | Repudiation            | 操作无法追责/敏感值进日志       | 中    | 中    | security/ops        | 追加式审计、request ID、脱敏日志                     | 管理员账号共享仍有风险       |
| T-05 | Information disclosure | 证据/联系方式/提取码泄露        | 中    | 高    | web/db              | 私有存储、DTO 白名单、加密、日志扫描、权限审计       | 服务器被完整攻破仍需事件响应 |
| T-06 | Denial of service      | 搜索/提交/登录/跳转被刷         | 高    | 中    | web/ops             | 分端点限流、机器人防护、队列背压、缓存               | 分布式攻击需上游防护         |
| T-07 | Elevation              | admin 管理接口越权              | 中    | 高    | web/security        | 权限矩阵、二次校验、敏感操作审计、CSRF               | 业务规则新增需测试           |
| T-08 | SSRF                   | 外链检查访问私网/云元数据       | 中    | 高    | cloud-drives        | URL/IP/DNS 二次校验、超时/大小/重定向限制、隔离网络  | DNS 与基础设施仍需持续验证   |
| T-09 | Open redirect          | `/go` 接受任意 URL 或禁用渠道   | 中    | 高    | web/cloud-drives    | 只接收 ID、数据库读取、域名白名单、模板白名单        | 官方域名规则变更需复核       |
| T-10 | Supply chain           | 恶意依赖/镜像/脚本              | 低-中 | 高    | ops                 | 锁文件、扫描、CodeQL、镜像固定、最小权限             | 零日漏洞需应急升级           |
| T-11 | Rights abuse           | 未授权资料通过伪造声明发布      | 中    | 高    | reviewer/compliance | 证据、审核、黑名单、投诉/恢复、抽查                  | 权利判断需要人工/法律支持    |
| T-12 | Metric fraud           | 点击伪装成官方转化              | 中    | 中-高 | analytics           | click/conversion 分表、验签/导入、外键去重、明确口径 | 外部报表错误需审计           |

## 4. 高优先级测试用例

- URL：`http/ftp/file`、用户信息段、localhost、IPv4/IPv6/十进制/八进制、私网/保留地址、非标准端口、混淆 IDN、DNS rebinding、多层重定向、超大响应。
- 授权：editor 审核自己、低权限访问证据、修改已发布权利/链接、过期/撤回/投诉资源搜索/详情/跳转。
- Web：CSRF、XSS/Markdown、开放重定向、路径枚举、越权、重复提交、错误响应和客户端包敏感字段扫描。
- 分析：重复快速点击、管理员/机器人流量、伪造回调、重放回调、过期事件删除、IP/UA/Referer 泄漏。
- 运维：Worker/Redis/Meilisearch 断开、outbox 重试/死信/幂等、备份恢复、密钥轮换。

## 5. 风险接受原则

未能证明权利、链接安全或转化真实性时，默认拒绝公开、返回 `unknown` 或需要人工复核。任何为提高召回/转化而降低合规或 SSRF 防护的改动都需要 ADR、测试和用户确认。
